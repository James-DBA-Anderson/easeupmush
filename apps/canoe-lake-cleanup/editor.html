Fencing

Closed perimeter. Drag points and arrow-nudge like the shore. Path spurs cut gateways.

Play park

Wood-chip boundary. Drag corners or click an edge to insert. Empty click seeds a small rectangle if none exists.

Car park

Asphalt boundary. Drag corners or click an edge to insert. Empty click seeds a rectangle if none exists. Cars fill the pad in-game.

Beach

Sand / shingle boundary. Drag corners or click an edge to insert. Empty click seeds a strip if none exists. The sea starts from the south edge of this zone.

0.60 m
Edge

Closed berm outline. Drag corners, click an edge to insert, Add berm for another. Height raises the top; Edge picks wall, steps, or slope down to the park.

Buildings & kit

Pick from the side catalog. Unique hire buildings select in place; cafés, bus stops and play kit stamp on empty clicks. Yaw in the preview (or Shift-drag).

Bins
Edit

Click the map to place. Drag or arrows to move, Delete to remove. Auto bins clears the list so the game spaces them on the path lip.

Kind
Bed yaw
Edit

Click to place trees, shrubs, or flower beds. Only these appear in the game. Drag / arrows move; [ ] rotate a selected bed; Delete removes.

Mission
When

Window on the shift clock. Game start / game end follow clock-on and end of shift; times are local park hours (wraps past midnight).

Edit

Red pins = wired jobs. Amber pins = placeholders (name + window only — fill in later). Drag / arrows move; Delete removes placeholders.
